## 🧠 Aprendizaje aplicado

En este laboratorio se aplicaron conceptos fundamentales de **gestión de estado en Jetpack Compose**, permitiendo una comprensión progresiva de cómo construir interfaces reactivas y mantener el control de los datos visualizados en pantalla. Los aprendizajes clave fueron:

- ✅ **Uso de `remember` y `mutableStateOf`** para almacenar el estado de los checkboxes dentro de la composición.
- 🔄 **Restablecimiento del estado** mediante la implementación de una función que limpia todas las selecciones.
- 📤 **Elevación del estado**, moviendo el control del estado de cada ítem hacia un componente superior para lograr una arquitectura más clara y reutilizable.
- 📋 **Trabajo con listas** usando `LazyColumn` para representar dinámicamente una colección de elementos con su estado correspondiente.
- 📦 **Uso de `mutableStateListOf`** para manejar una lista observable de objetos personalizados (`ItemState`), logrando una reactividad fluida en cada cambio de estado.
- 🧠 **Gestión de estado en `ViewModel`**, separando la lógica de presentación de la interfaz, aplicando buenas prácticas de arquitectura y facilitando la escalabilidad del proyecto.
